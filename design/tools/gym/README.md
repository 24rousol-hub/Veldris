# Gym builders

Map builders: run only when the author asks for a map to be built (CLAUDE.md rule 2); edit in Porymap afterwards.

| Script | What it does |
|---|---|
| `vrail.py` | Draws the north-south railing pieces (straight, two ends, two joins) from the Petalburg gym railing's colours |
| `gym_rails.py` | Adds those pieces to `gTileset_PetalburgGym` as metatiles 736-740 (re-runnable) |
| `crestfall_gym.py` | Crestfall Gym: layout, map, scripts, the Crestfall door warp and the TM CRUNCH flag alias |
| `mrender.py` | Layout renderer (copy of `design/tools/interiors/mrender.py`) |

Run from this folder.
